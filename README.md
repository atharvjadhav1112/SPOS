## 📘 About This Repository
This repository contains all **System Programming and Operating System (SPOS)** laboratory programs for **Third Year Computer Engineering (TE Comp)** under the **Savitribai Phule Pune University (SPPU) 2019 Pattern**.

Each folder includes commented code, output screenshots, and explanations covering topics like **assemblers, macro processors, scheduling, memory management, synchronization, and dynamic linking** — helping students easily understand and execute SPOS experiments.

---

## 📂 Repository Structure
SPOS-Lab/
│
├── A3_Dynamic Link Library/ # Implementation of dynamic linking and loading
├── Assembler/ # Pass 1 and Pass 2 assembler programs
├── MacroPass/ # Macro processor design and implementation
├── MemoryManagement/ # Memory allocation algorithms (Best, First, Worst Fit)
├── PageReplacement/ # FIFO, LRU, Optimal page replacement algorithms
├── Scheduling/ # FCFS, SJF, Priority, and Round Robin scheduling
└── Synchronization/ # Process synchronization using semaphores, deadlock avoidance

## 🧩 Syllabus Overview (SPPU 2019 Pattern)
| **Unit No.** | **Title** | **Key Concepts** |
|---------------|------------|------------------|
| 1 | Introduction to System Software | Assemblers, Loaders, Linkers, Macro Processors |
| 2 | Macro Processor | Pass structure, macro expansion, argument processing |
| 3 | Process Management | Process states, CPU Scheduling Algorithms |
| 4 | Memory Management | Allocation & Replacement (Paging, Segmentation, FIFO, LRU) |
| 5 | I/O and File Management | Device drivers, dynamic linking, file allocation |
| 6 | Synchronization & Case Studies | Semaphores, Deadlock Handling, OS for Embedded/IoT Systems |
